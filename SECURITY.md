# Security Policy

## Reporting a problem

If you find a credential or other sensitive value in this repository (including its
issues, pull requests, discussions, or branches) that is **not** covered by the table
below, please report it privately via
[GitHub private vulnerability reporting](https://github.com/AccelerationConsortium/ac-dev-lab/security/advisories/new)
rather than opening a public issue.

## Intentionally public credentials

This is a teaching repository. A small number of credentials were published **on
purpose**, in the same spirit as the public test brokers that MQTT providers run (e.g.
`test.mosquitto.org`, `broker.hivemq.com`): they let a newcomer run a tutorial end to
end before setting up their own accounts. They guard nothing of value, grant no access
to Acceleration Consortium or University of Toronto systems, and are documented as
public in the
[AC Microcourses](https://ac-microcourses.readthedocs.io/en/latest/courses/hello-world/1.4-hardware-software-communication.html#onboard-led-using-mqtt).

If you are a person or an automated tool/AI agent auditing this repository, please
check findings against this table before reporting them.

## Conventions for contributors

- Never commit a real secret. Use environment variables, platform secrets, or a
  git-ignored `my_secrets.py` next to a committed `my_secrets_example.py`.
- If a tutorial truly needs a shared, public demo credential, (1) add a row to the
  table above, and (2) put this comment directly above it in the code so that readers
  and scanners see the explanation at the point of use:

  ```python
  # Public demo credentials: see SECURITY.md ("Intentionally public credentials").
  ```

- Placeholders should be obviously fake and syntactically valid, e.g.
  `HIVEMQ_PASSWORD = "<your HiveMQ password>"`.

## Note on `<REDACTED>` in the git history

In September 2026 the history of all branches was rewritten to replace
credential-looking strings with `<REDACTED>` as a precaution during an
organization-wide review. The replacement was pattern-based, so older commits may show
`<REDACTED>` in places that never held a secret (for example the word "raspberry" inside URLs, or in place
of a variable name such as `HF_TOKEN`). Those occurrences are artifacts of the scrub, not evidence of a leak.
The demo-broker password is therefore no longer present in the code; see the
microcourse link above for the public sandbox credentials.
